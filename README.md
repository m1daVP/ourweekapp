# OurWeek

OurWeek is a guided weekly check-in app for couples and families. It helps turn conversations into shared notes, tasks, agreements, and follow-ups that can be revisited later.

This monorepository contains the complete source code for the OurWeek project submitted to the RevenueCat Shipaton 2026 Next Gen category.

## Repository structure

* [`mobile/`](./mobile) — mobile application
* [`backend/`](./backend) — backend services and API

Each directory contains its own README with detailed setup instructions, architecture notes, environment configuration, and development documentation.

## Running the project

See the setup instructions in:

* [`mobile/README.md`](./mobile/README.md)
* [`backend/README.md`](./backend/README.md)

No production credentials or private environment variables are included in this repository.
